## 7. 已知缺口

1. **PolicyGuard 为透传空壳**：规则目前在 ProposalValidator 中执行，PolicyGuard 只保留入口类型。属于 Phase 7 边界预留，不影响安全。
2. **真实 LLM happy path 未手动验证**：当前环境无可用的 API key，需要在真实 Obsidian 中配置后手动验证。
3. **between-headings protected region mode**：仅类型预留，未实现。
4. **draft 写入的 vault adapter**：当前使用 ObsidianNoteRepository 中的简化实现，未单独做 ObsidianFileWriter。
